1. FAUNA EXTRACTION — USE A REAL AVAILABLE MATCHING SOURCE
==================================================

Current confirmed defect:

A generic local fauna request can select the matching stock with the highest STATIC carrying capacity, then discover that this stock is exhausted.

A separate overlapping matching source may still be physically healthy, but is never considered.

This turns real physical food into inaccessible food.

Chosen correction:

For GENERIC local tile/class physical extraction:

1. enumerate the bounded physically matching sources already represented at the reached location;
2. evaluate their CURRENT extractable availability using existing:
   - seasonal rules;
   - reserve rules;
   - activity eligibility;
   - dynamic abundance;
3. choose the source with the greatest legitimate currently extractable amount;
4. use deterministic physical identity as tie-break;
5. the chosen exact source must own:
   - take;
   - depletion;
   - returned provenance.

Do not test candidates by mutating/depleting them.

Use a pure availability calculation before choosing.

IMPORTANT:

Generic execution may choose among physically present matching sources.

Explicit known-source targeting is different.

If a human action explicitly targets a known identified source:
- retain that identity;
- if that exact source is exhausted/absent, do not secretly redirect the humans to an unknown source.

Do not leak hidden abundance into decisions.

Decision:
human-known evidence.

Execution:
physical truth at the reached location.

Preserve that separation.

Required RED:

existing overlapping-source witness where:
- static winner = reserve/exhausted;
- second matching source = healthy;
- old generic extraction = 0;
- corrected generic extraction uses the real second source.

Controls:

- both exhausted;
- no source;
- predator/ineligible source;
- seasonal ineligibility;
- stable tie;
- repeat depletion;
- same physical stock appearing through overlapping geography must not double count;
- explicit source target does not silently redirect;
- source provenance of returned food is exact.

Restore the old static-winner mechanism as a mutant and behaviorally detect it.
